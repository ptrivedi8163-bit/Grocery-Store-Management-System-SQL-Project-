# Grocery-Store-Management-System-SQL-Project-
A practical database project demonstrating how SQL can be used to manage inventory, sales, customers, and reporting for a retail grocery store.

**Project Name**
*Grocery Store Management System*

**Project Objective**
To design and implement a relational database system for a grocery store that manages products, inventory, sales transactions, customers, and suppliers. The project aims to improve data organization, automate reporting, and support business decision-making through SQL queries and data analysis.

**Tools & Technologies Used**
MySQL Workbench
SQL (DDL, DML, Joins, Aggregations, Subqueries)
Microsoft PowerPoint (for project presentation and documentation)

**Key Insights**
Tracked product-wise sales performance and identified top-selling items.
Monitored inventory levels to detect low-stock products and support restocking decisions.
Analyzed customer purchase patterns using transaction data.
Generated reports for total sales, revenue, and product category performance.
Used SQL joins and aggregation functions to combine data from multiple tables and produce meaningful business reports.
Demonstrated how a structured database system can improve operational efficiency and reporting accuracy in a retail environment.
